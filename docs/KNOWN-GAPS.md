# 已知資料缺口

取自 HANDOFF.md §4，逐點列出症狀、偵測方式與處理方式。頁尾需固定顯示。

## 1. MHT 存檔不完整

- **症狀**：分頁未載入完就存檔，資料缺漏但 DOM 結構正常。
- **偵測**：S3 稽核，逐投手加總與球團表比對打數、安打、全壘打。
- **處理**：差異寫入報告，不中止；差異大的球團標記需重存。

## 2. 球團歸屬不可信

- **症狀**：Short-Stop 標示球團與投手實際所屬不符（含轉隊未更新）。
- **偵測**：S5 比對，主鍵 `球團|姓名` 查不到時記錄回退次數。
- **處理**：退回以姓名全聯盟查找；查不到留空、列入未命中清單，絕不猜測。

## 3. 樣本極小

- **症狀**：拆成球團 × 左右後每格僅 6–34 個打數，比率易失真。
- **偵測**：聚合時檢查 `ab` 是否低於門檻。
- **處理**：打數低於 10 不顯示打率；超過門檻仍需與打數並列。

## 4. NPB 頁面成本高

- **症狀**：單頁約 9000 token，逐投手查詢成本過高。
- **偵測**：S4 前檢查本地快取是否存在且未過期。
- **處理**：改抓球團名冊本地比對，快取帶抓取日期。

## 5. 賽季進行中名冊會變動

- **症狀**：轉隊、育成升支配下等異動使過期快取被誤用。
- **偵測**：讀取快取時比對快取日期與當日日期。
- **處理**：快取過期即重抓；S4 該球團標記未命中並繼續。
